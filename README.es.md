## 🚀 &nbsp;Proyecto Principal — Plataforma VIA

> Un **ERP domain-driven** de producción que reemplaza una década de Excel, firmas en papel y carpetas fragmentadas de Google Drive para un operador de transporte de pasajeros regulado por el *Ministerio de Transporte*.
